# SceneNFO

SceneNFO scans Radarr and Sonarr media libraries, classifies releases as Scene or P2P using exact PreDB.club matches, manages Scene NFO files from srrDB, PreDB.club and crowdNFO, and provides live scans, history, logs, schedules and import automation.

> This project is vibe-coded / AI-assisted and is not professionally third-party audited.

# SceneNFO

SceneNFO is a Docker application for scanning Radarr and Sonarr media libraries, classifying releases as Scene or P2P, and managing `.nfo` files from srrDB, PreDB.club and crowdNFO.

## Features

- Radarr and Sonarr library scanning
- Scene / P2P classification
- Scene NFO lookup and management
- srrDB, PreDB.club and crowdNFO integration
- Live scan progress and history
- Scheduled scans
- Import automation and webhooks
- Dashboard with recently added media and scan status
- Docker / Unraid deployment

## Development note

This project is developed with substantial AI assistance / vibe-coding. Changes should be reviewed and tested before production use.
